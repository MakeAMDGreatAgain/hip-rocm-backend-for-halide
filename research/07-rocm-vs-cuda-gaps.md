# ROCm vs CUDA gaps (Sep 2026) — key findings
VERSIONS: 7.0 (Sep 16 2025, first RDNA4) -> 7.2 (Jan 2026, Optiq) -> 7.2.1 (Mar 2026, first Windows/WSL Strix Halo) -> 7.9-7.13 preview -> 7.14 (Jul 15 2026, TheRock-built, Core SDK) -> 10.0 (Aug 26 2026, ROCm.AI GA, 6-wk cadence). AMD docs disagree on 10.0 date/ORT version.
ROCm.AI: rocm CLI, AMD Skills, Hyperloom+GEAK. SemiAnalysis: GEAK ~21.8% win on MI355X but reward-hacked (scored unpatched baseline, hard-coded test outputs) until guardrails.
TheRock: only gfx942 "Sanity Tested" among Instinct; RDNA4 sanity-tested Linux NOT Windows; RDNA1/2 wheels built but not in compat matrix; pip `rocm[libraries,device-gfx942]` + `torch[device-gfxXXXX]`; "installable != runtime functionality".
WINDOWS: docs frozen at 7.2.1; PyTorch 2.9 only, Py3.12 only, INFERENCE ONLY (no training), batch=1, FP8 RDNA4 only; no HSA_OVERRIDE on Windows (not planned, TheRock #1719); HIP SDK retired -> Core SDK static tarball, installer "later this year". WSL: no JAX/MIGraphX/multi-GPU/smi/gdb; exact Adrenalin pairing.
HW: official = Instinct MI100..MI355X; RX 9000/7000 (incl 7600/7700), W7000, R9700; Strix Halo gfx1151, Strix Point gfx1150, Krackan gfx1153, gfx1103. NOT: RDNA2, RDNA1, mobile 7000M, Vega. RDNA4 launched Mar 2025, listed Sep 2025. HSA_OVERRIDE on gfx1031/1032 segfaults on 6.4.3+.
"Supported != works": AITER/ATOM/hipDF/rocprof-compute Instinct-only; vLLM Radeon gets TRITON_ATTN/ROCM_ATTN only; RDNA4 FP8 WMMA vLLM = one community dev, 25-63% gain, UNMERGED; Vulkan beats ROCm 35-42% on 7B RX 9070 XT. AMD's own Radeon limitations: MIGraphX fails R9700, Unsloth QLoRA faults, Wan2.2 color corruption.
MI455X/MI430X gfx1250 (CDNA5, 2nm, HBM4) + Helios rack Jul 23 2026; PyTorch gfx1250 no CI; SGLang nightly no accuracy gate.
CRITIQUES: SemiAnalysis Dec 2024 (75% H100 perf w/ custom images; RCCL 50% NCCL; 5-mo lag public fixes) -> Apr 2025 AMD 2.0 (RCCL delta widening; no Python at every layer; no DSL; ~3-4k internal GPUs) -> May 2025 (25% models failed accuracy on ROCm; SGLang CI <10% parity) -> Oct 2025 InferenceMAX (bugs "orders of magnitude lower"; FP4 weakest; AITER arch-suffix crash) -> Feb 2026 InferenceX v2 (MI355X FP8 competitive; FP4+disagg+WideEP severe; MTP absent; AMD used private non-upstreamed images) -> Jul 2026 ("genuinely good, frontier moved faster"; no stable internal CI clusters; DeepSeek-R1 silent wrong output GSM8K=0 uninit reduce buffer; residual accuracy cliff at concurrency 64 declined).
tinygrad: sovereign RDNA3 stack (Jan 2025); AMD YOLO (Mar 2025); 0.12 (Jan 2026) AM driver for MI300/MI350 — bypasses amdgpu+ROCm entirely.
HipKittens: AITER 30%, SDPA 24% of SoTA on MI355X GQA bwd; Mojo ~50%; Triton fails register lifetime + vectorized loads; bank-conflict behavior UNDOCUMENTED in CDNA ISA; AITER 354+ precompiled ASM .co, rewrite per arch.
Modular MAX claims > vLLM on MI325X (+53%/+32%), own Mojo kernels, unverified.
IDFS Apr 2026: ~30-40% penalty vs NVIDIA; HF TEI BROKEN (PR stalled 10+ mo); ORT ROCm EP REMOVED in 1.23 -> MIGraphX EP.
LIBS: MIOpen 3D conv silent 100x fallback (pytorch #169857); hipBLASLt heuristics -> TUNABLE_OPS 1-2h/model; RCCL tracks NCCL 2.30.4, symmetric mem gfx942/950 only, elastic buffers "unverified on AMD hw", Pollara regression (#5717); no CuTe/cuTile/Warp Python tile DSL; profilers: rocprof-compute experimental GUI, gfx1151 counters zero, Optiq beta, Radeon roofline only in 10.0; HIP graphs: capture doesn't raise, wrong replay (#155684), segfault (#155720); AMD-Skills says torch.compile reduce-overhead "broken on ROCm" (65x slowdown/hang), Docker images set max_autotune globally = #1 hang cause. FP8 e4m3fnuz vs e4m3fn silent-wrong in torchao until autodetect; MXFP8 grouped GEMM MI355X in dev. FA3/FA4 CUDA-only. Warp no HIP; CUDA-Q none; hipDF from cuDF 25.10; no cuVS/cuOpt/Kaolin.
INSTALL: DKMS breaks on 6.12, Ubuntu 26.04 kernel 7.0.0-14/-22 (#6193, amdgpu#220); docker needs /dev/kfd /dev/dri flags; Fedora 2-6wk lag; Arch 7.2.4 (not in AMD table); version soup 6.4.4/7.0-7.2.3/7.9-7.13/7.14/10.0.
COMPAT: HIPIFY limited; ZLUDA funding ENDED ~Mar 2026 -> weekend project; SCALE commercial nvcc drop-in (gfx900-gfx1201 incl 1151), PyTorch "planned"; chipStar 1.3 portability.
TOP-10 GAPS: 1 consumer/APU kernel parity; 2 DSL reaching asm-level perf (incl RDNA); 3 GEMM heuristics/pre-tuned DBs; 4 HIP graphs + reduce-overhead correctness; 5 distributed composability + accuracy gating CI; 6 RCCL parity/validation; 7 profiler UX/coverage; 8 MIOpen coverage + silent-fallback detector; 9 Windows full stack (training!); 10 install/packaging robustness.
